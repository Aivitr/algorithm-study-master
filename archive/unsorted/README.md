# 未归类 · **本目录有意为空**

`docs/待验收事项.md` A11 把本目录列为归档目标之一，用途是**接下来**收纳
「属于历史产物、但不属于任何现有子目录」的文件。

本次归档**没有任何文件归入**——A11 的全量清点把所有待归档文件都映射到了明确的
去处（`speech-stages/` `dev-docs/` `ops-scripts/` `legacy-tests/` `prototypes/`）。

本目录保留，是为了下次遇到"确属历史、但一时定不下归属"的文件时有个默认去处，
不必临时新增目录名。

---

## 为什么不按 A6「空目录删除」处理

A6 决定移除 `steploc/` `templates/` `static/` `assets/` 四个空目录，那四者是
**CDN 化之前的残留骨架**——没有任何意图，删掉是清理。

本目录不同：它的"空"是**一条已登记的约定**（A11 明确写了「留空备用」），
删掉会让那条约定失去落点。用一份 README 说明意图，它就不再是无人认领的空目录。

（技术上也有必要：git 不跟踪空目录，不放 README 的话，本目录在克隆后根本不会出现。）

## 十、学习报告

课后自动生成完整学习报告，包含：

1. **课程总结** - 整体讨论内容概述
2. **讨论核心问题** - 主要讨论的问题列表
3. **主要观点汇总** - 各方观点及支持理由
4. **讨论亮点** - 最有启发/最具争议的观点
5. **达成的共识** - 讨论中形成的共识
6. **未解决问题** - 待进一步研究的问题
7. **后续行动计划** - 下一步研究方向
8. **个人收获与反思** - 每个学生的个性化点评

## 系统架构

```
┌─────────────┐     WebSocket      ┌─────────────┐
│   用户浏览器  │ ◄──────────────► │  FastAPI    │
│  (Vue.js 2) │                   │  服务器      │
└─────────────┘                   └──────┬──────┘
                                         │
                    ┌────────────────────┼────────────────────┐
                    │                    │                    │
              ┌─────▼──────┐      ┌─────▼─────┐      ┌──────▼──────┐
              │  阿里云 NLS │      │  DeepSeek │      │ SQL Server  │
              │  实时语音转写│      │   大模型   │      │    2022     │
              └────────────┘      └───────────┘      └─────────────┘
```

上图的 WebSocket 只承载信令、字幕与统计等**文本**通道。
实时音视频不走 FastAPI：浏览器用 Agora RTC SDK 直连 Agora 云，
由后端签发的频道 Token（`GET /api/agora-token`）授权。

## 技术栈

| 模块 | 技术 |
|------|------|
| 前端 | Vue 2.6.14 + Tailwind 2.2.19 + ECharts 5.4.0 |
| 后端 | FastAPI + Starlette + Uvicorn，含 WebSocket |
| 实时音视频 | Agora RTC SDK 4.22.0（信令走 `/ws-signal/...`） |
| 语音识别 | 阿里云 NLS 实时转写；浏览器端 Web Speech 作兜底 |
| 大模型 | DeepSeek API（`openai` 兼容接口）；可切换本地 Ollama |
| 数据库 | **SQL Server 2022**，经 `pymssql` 走 TDS 协议 |
| 视觉与音视频 | OpenCV（Haar 级联人脸检测）+ FFmpeg |
| 运行环境 | Python 3.12 |

前端所有第三方库**本地化在 `static/vendor/` 下，页面不依赖公网 CDN**；
版本、来源与 SHA256 见 `static/vendor/SOURCES.json`。
